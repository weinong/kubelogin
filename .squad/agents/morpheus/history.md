# Project Context

- **Owner:** Weinong Wang
- **Project:** kubelogin — a `kubectl` credential (exec) plugin that handles non-interactive Azure AD / Entra ID authentication for Kubernetes clusters. Supports multiple auth modes: devicecode, interactive, spn, workload identity, msi, ropc, azurecli.
- **Stack:** Go, Kubernetes client-go exec credential plugin protocol, MSAL-Go, Azure AD / Entra ID OIDC
- **Created:** 2026-05-25
